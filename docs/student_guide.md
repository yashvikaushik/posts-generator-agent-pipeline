# Student Onboarding & Project Kick-Off Guide

Welcome to the **Shruti Sadhana AI Studio** project! This guide is designed to help you understand the purpose, core technologies, and sequential flow of this application before writing a single line of code. 

Think of this document as your roadmap. Let's break down the "what," "why," and "how" of this multi-agent automation project.

---

## 1. The Project Agenda (What are we building & why?)

### The Core Problem
Creating high-quality social media content (like Instagram carousel posts) about complex, traditional topics (like Sanskrit Shlokas) requires several distinct tasks:
1. Translating and researching historical Sanskrit scriptures.
2. Formulating an engaging storytelling arc.
3. Writing script drafts for each slide.
4. Outlining a unified visual color/typography theme.
5. Generating custom, descriptive illustrations.
6. Reviewing everything for factual accuracy.

Doing this manually is time-consuming and requires research, design, and copywriting skills.

### Our Solution
We are building a **Multi-Agent AI Pipeline**. Instead of having a single AI model try to do everything at once (which usually results in generic or messy output), we split the work among **7 specialized AI agents** that run sequentially (one after the other). 

As a student, your goal is to learn how to:
*   Connect a React frontend dashboard to an Express backend server.
*   Establish real-time data streaming (so the user sees logs update live).
*   Structure LLM (GPT-4o) prompts to output clean JSON instead of raw text.
*   Orchestrate and coordinate sequential processes in Node.js.

---

## 2. The Tech Stack Explained Simply

Here is what each tool in our toolbox does:

| Technology | What it is | Why we use it for this project |
| :--- | :--- | :--- |
| **Vite + React** | Frontend Framework | Helps us build a fast, component-based user interface. It manages what the user sees on the screen (the forms, progress bars, logs, and slide editors). |
| **Bootstrap & CSS** | UI Styling Library | Bootstrap gives us a clean, responsive layout grid out-of-the-box. We use custom CSS over it to build the custom glassmorphism style (glowing dark themes, rounded cards, sleek fonts). |
| **Node.js + Express** | Backend Server | The server listens for requests from the React app (like "launch a mission") and runs the JavaScript code that talks to OpenAI and handles files. |
| **Socket.io (WebSockets)** | Real-Time Connection | Normal APIs use request-response: the browser asks, and the server answers. But AI takes minutes to run. WebSockets allow the server to keep a pipeline open and push live updates (like log lines) to the UI as they happen. |
| **OpenAI API (GPT-4o)** | Large Language Model | Acts as the "brains" of our agents. We send specific instructions (prompts) to GPT-4o to do the research, writing, planning, and quality audits. |
| **DALL-E 3** | Image Generator API | Takes prompt descriptions from our Creative and Image Prompt agents and generates custom slide backgrounds. |
| **adm-zip** | Node Zip Utility | A backend library that takes the text and images generated by the agents, packages them into a single ZIP file, and serves it to the browser for download. |

## 3. The Sequential Agent Flow (How data moves)

Rather than passing all instructions to one prompt, our pipeline operates like an assembly line:

```text
[Topic Input] 
     │
     ▼
[1. Sanskrit Research Agent]  ──> Translates & gathers authentic commentary.
     │ (outputs research text)
     ▼
[2. Narrative Architect]      ──> Transforms research into an emotional storyline.
     │ (outputs narrative outline)
     ▼
[3. Carousel Planner]         ──> Plans logical slides (Hook, core lessons, CTA).
     │ (outputs slide layout blueprints)
     ▼
[4. Carousel Writer]          ──> Writes exact slide text, Instagram captions, & tags.
     │ (outputs slide copies & caption strings)
     ▼
[5. Creative Director]        ──> Outlines visual styling rules (colors, fonts, mood).
     │ (outputs visual guide instructions)
     ▼
[6. Image Prompt Director]    ──> Converts style descriptions into DALL-E prompts.
     │ (outputs generated image assets)
     ▼
[7. Layout Designer]          ──> Places texts, applies final styling layers.
     │
     ▼
[Final Content Package]       ──> Ready for review, editing, and ZIP export.
```

## 4. Key Technical Concepts to Master

Before coding, make sure you understand these concepts:

### A. Asynchronous Operations
In JavaScript, operations that take time (like fetching data from OpenAI) are written asynchronously using `async/await`. Since running 7 agents takes several minutes, your server must process this in the background so the user's browser doesn't think the website has crashed.

### B. Client-Server Separation
*   **The Client (React)** does not talk to OpenAI directly. This keeps API keys hidden securely on the server.
*   **The Server (Express)** holds the API keys, runs the agents, and saves generated outputs locally.

### C. JSON Formatting (Structured AI Outputs)
For the backend to pass data between agents (e.g. Narrative Architect passing output to Carousel Planner), the AI must return clean data. We instruct GPT-4o to return structured JSON (using JSON mode or Structured Outputs) rather than conversational text.

## 5. Your Learning Path (Recommended Build Order)

When you are ready to start coding, follow this order:

1.  **Initialize the Backend:** Set up an Express server, connect the OpenAI API wrapper, and test a single test prompt.
2.  **Establish WebSocket Communication:** Connect Socket.io on the backend, and write a simple route that sends simulated "logs" every few seconds to test live streaming.
3.  **Build the Agent Chain:** Code the 7 agents sequentially. Verify that the output of Agent 1 goes correctly into the prompt of Agent 2, and so on.
4.  **Assemble the Frontend UI:** Create the React workspace using Vite. Build your input forms, style them with Bootstrap, and connect your Socket listener to show live log cards.
5.  **Add Review & Export:** Render the generated slide content in React cards, write API routes to edit them, and implement the ZIP compilation download logic.
